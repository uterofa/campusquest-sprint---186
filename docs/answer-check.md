# Проверка ответа

## Зачем нужна
Функция принимает введенный пользователем ответ, сверяет его с правильным решением в базе данных и мгновенно сообщает результат проверки.

## Пользовательский сценарий
1. Студент находит разгадку, вводит слово или кодовое число в текстовое поле на карточке.
2. Нажимает кнопку «Проверить ответ».
3. Система сверяет данные и подсвечивает поле зеленым (верно) или красным (ошибка).

## Критерий готовности
- Система нечувствительна к регистру букв при проверке текстовых ответов (например, «Библиотека» и «библиотека» — оба верны).
- При неверном ответе выводится сообщение с предложением попробовать ещё раз.

## Риск или вопрос
- Защищена ли база данных с правильными ответами от просмотра через код страницы (DevTools)?
