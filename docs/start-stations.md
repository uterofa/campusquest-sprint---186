# Стартовый экран и Список станций

## Зачем нужна
Функция позволяет первокурснику запустить игровой квест, ознакомиться с правилами и увидеть интерактивный список доступных локаций (станций) для прохождения.

## Пользовательский сценарий
1. Студент открывает приложение и нажимает кнопку «Начать квест» на приветственном экране.
2. Система отображает карту или список учебных корпусов с точками-станциями.
3. Студент выбирает первую доступную станцию, чтобы перейти к заданиям.

## Критерий готовности
- Кнопка старта корректно перенаправляет на список станций.
- Все заблокированные станции отображаются с иконкой замка.

## Риск или вопрос
- Будет ли список станций обновляться динамически в зависимости от геолокации пользователя?
