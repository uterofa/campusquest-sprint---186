# Технические компоненты командного режима
Функция декомпозирована на 3 минимальные части:
1. Сервис генерации коротких кодов сессий в базе данных.
2. Модуль авторизации и добавления игроков в комнату по коду.
3. Механизм синхронизации общего счета и статуса станций.
Зависимости: разработка заблокирована до утверждения новой архитектуры БД.
