# Ограничения и правила MVP командного режима
1. Лимит сессии: строго максимум 4 игрока.
2. Идентификация комнат происходит исключительно по сгенерированному коду.
3. Реализован единый счет на всю команду без личных рейтингов.
4. Чат, уведомления и распределение внутренних ролей исключены из релиза.
