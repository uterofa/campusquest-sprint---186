# Пошаговый сценарий командного взаимодействия
1. Капитан нажимает кнопку создания команды.
2. Система генерирует уникальный код сессии.
3. Остальные участники вводят данный код и подключаются к лобби.
4. Команда проходит станции, любой участник может отправить ответ.
5. Очки суммируются в единую копилку, экраны синхронизируются.
